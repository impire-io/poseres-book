## LinkedIn

A book about a machine that learns in front of you should let it learn in front of you. Two commands, on any machine with Python:

pip install poseres
pra-rover

A browser page opens. A small rover wanders a walled arena with five obstacles, reading a five-beam rangefinder, a compass, a position beacon, and a bumper. Its movements are random and stay random. The demo isn't the driving. It's the three quantities moving beside the arena: prediction error falling with no training phase and no labels, frames spawning and being evicted while the population holds around fifteen residents that no line of code names, and best_dim settling at 2, run after run.

The viewer observes without perturbing. A run with the browser page open is byte-identical to the same run with nobody watching, and a paced, watchable run is byte-identical to an unthrottled one. That is tested rather than assumed, because an instrument that changes the experiment can't be trusted about the experiment.

The same seam carries Gymnasium games through an adapter of about fifty lines and real robots through ROS2, where every topic a robot publishes becomes a sensor. The Gazebo example earned its place on its first run: the summary printed nan early, nan late while the exit code reported success. A lidar reports infinity for "no hit," and those values marched through the pipeline and poisoned every accumulated error statistic. Chapter 8's worlds were clean. Real sensors are not.
